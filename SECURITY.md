# Security Policy

## Reporting a software vulnerability

If you discover a security vulnerability in this codebase (e.g. in
`teslasuit_rapidkit`, the examples, or a dependency), please report it
privately rather than opening a public issue.

**Email support@teslasuit.io** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce, including affected version(s)
- Any suggested fix, if you have one

We aim to acknowledge reports within 5 business days and will keep you
updated as we investigate and resolve the issue. Please give us reasonable
time to address a vulnerability before any public disclosure.

## Not a channel for hardware or stimulation safety incidents

This policy covers *software* security issues in this repository (code,
dependencies, data handling). It is **not** the right channel for a safety
concern involving the Teslasuit device itself, an adverse event during
electrical stimulation, or any other hardware/clinical safety issue — those
should go through Teslasuit's normal support channel
(**support@teslasuit.io**, subject line noting it's a hardware/safety
matter) rather than being reported as a code vulnerability.

## Scope

This policy applies to the `teslasuit_rapidkit` framework and the example
applications in this repository. It does not cover the Teslasuit Python SDK
or Teslasuit Studio/Control Center, which are Teslasuit's separately
maintained products.
